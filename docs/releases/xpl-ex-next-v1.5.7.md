# Изменения относительно XPL-EX-NEXT v1.5.6

- Исправлено отображение результата сохранения в русской локализации: вместо `%1$s` и `%2$s` теперь показываются реальные количества успешно сохранённых настроек и ошибок.
- Глобальный **Spoof Device** больше не выбирает и не рандомизирует параметры раздела `zone`. Язык, Locale, TimeZone и ZoneId остаются выключенными по умолчанию и доступны только для отдельного ручного включения.
- Версия приложения и имя APK обновлены до **XPL-EX-NEXT 1.5.7**. Для совместимости хуков сохранены прежние `versionCode 155`, package name и bridge ABI.
