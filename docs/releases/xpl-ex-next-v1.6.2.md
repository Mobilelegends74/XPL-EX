# XPL-EX-NEXT v1.6.2

- Восстановлен приоритет сохранённого пользователем шаблона **Global Context** над автоматическим выбором параметров по назначенным приложению хукам. Это исправляет замечание из [issue #6](https://github.com/Mobilelegends74/XPL-EX/issues/6).
- Явно сохранённый шаблон теперь действует даже при **нуле отмеченных полей**: открытие настроек приложения не добавляет в него параметры хуков автоматически.
- Глобальные значения, заданные без галочки, продолжают служить общими значениями по умолчанию. Рандомизация приложения работает по отмеченным полям и не меняет глобальные значения. Например, `battery.charge.percent = 85,95` можно задать один раз в Global Context и оставить без галочки.
- Добавлен пункт **«Удалить глобальный шаблон»**: после его выбора автоматическое выделение параметров по назначенным хукам снова работает. Ранее сохранённые непустые шаблоны распознаются автоматически.
- Версия приложения и APK обновлена до `1.6.2` (`versionCode 167`); bridge-протокол совместимости сохранён на версии `1.5.5`.
- APK подписан тем же постоянным сертификатом, что и релизы v1.6.0–v1.6.1, поэтому устанавливается поверх них без удаления приложения.

После установки перезапустите XPL-EX. Чтобы сохранить свой набор отметок, откройте **Setting Values → Save Checked → Global**. Значения полей сохраняются отдельно обычной кнопкой сохранения настроек. Для применения изменений хуков к уже запущенным приложениям перезапустите эти приложения; при необходимости перезагрузите устройство.
