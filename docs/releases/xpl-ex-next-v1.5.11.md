# XPL-EX-NEXT v1.5.11

- Возвращены выпадающие селекторы для параметров **Settings Values**, имеющих конечный набор допустимых значений.
- Все логические параметры с суффиксом `.bool` снова предлагают выбор `True`/`False`, включая `battery.is.charging.bool` и `battery.is.plugged.in.bool`.
- Для `battery.status` доступны состояния Android: `Charging (2)`, `Discharging (3)`, `Full (5)`, `Not Charging (4)` и `Unknown (1)`.
- Варианты для других параметров автоматически берутся из их специализированных option-randomizer классов.
- Ручные селекторы отделены от механизма рандомизации: выбор отдельного значения не меняет привязку к согласованному профилю реального устройства.
- Версия приложения и APK обновлена до `1.5.11` (`versionCode 161`); bridge-протокол совместимости сохранён на версии `1.5.5`.

Изменение исправляет замечание из [issue #3](https://github.com/Mobilelegends74/XPL-EX/issues/3).

После установки необходимо перезагрузить устройство, чтобы LSPosed загрузил новую версию во все выбранные приложения.
