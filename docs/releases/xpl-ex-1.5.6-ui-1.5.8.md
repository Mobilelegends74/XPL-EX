# XPL-EX 1.5.6 (155) — UI 1.5.8 Final

Эта сборка основана на оригинальной ветке [`0bbedCode/XPL-EX:new`](https://github.com/0bbedCode/XPL-EX/tree/new). Ниже перечислены функциональные отличия нашей ветки от основной версии автора.

## Universal Gaming Spoof

- В начало списка хуков добавлен отдельный раздел **Universal Gaming Spoof → Spoof Device**.
- Один переключатель включает согласованный набор хуков модели и Android Build, SoC/CPU/GPU, RAM, дисплея, батареи, камеры, системных и рекламных ID, SIM/телефонии, сети, Wi-Fi, аккаунтов, языка, часового пояса, User-Agent и хранилища.
- Для фирменных Device ID выбирается только группа производителя текущего профиля. Одновременная активация Lenovo, ASUS, Meizu, Vivo, OnePlus, Samsung и Xiaomi устранена.
- Motorola не выдаётся за Lenovo: бренд и OEM ID остаются согласованными.
- Геолокация, контакты, VPN, микрофон и другие не относящиеся к идентификации разрешения мастер-переключателем не включаются.

## Реальные согласованные профили устройств

- Добавлен каталог реально существующих Google Pixel, ASUS/ROG, Lenovo Legion, Meizu, Motorola, Nubia/RedMagic, OnePlus, POCO, Samsung, Vivo/iQOO и Xiaomi.
- Для ASUS, Lenovo, Meizu и Vivo/iQOO добавлено по пять отсутствовавших моделей; также расширены остальные представленные бренды.
- Модель, brand, manufacturer, product, codename, fingerprint, Android/API и Build выбираются атомарно из одного профиля.
- С той же моделью согласуются SoC, CPU ABI, GPU, RAM, экран, батарея, число камер и аппаратные свойства.
- Рандомизация сбалансирована между брендами и больше не создаёт смешанные «модели-конструкторы».
- Валидатор отклоняет несовместимые Android/API, fingerprint и аппаратные характеристики до сохранения профиля.

## CPU, SoC и GPU

- `/proc/cpuinfo` генерируется из выбранного профиля: меняются название процессора, число ядер и SoC.
- `Build.SOC_MODEL`, `Build.HARDWARE`, `Build.BOARD` и `Runtime.availableProcessors()` связаны с профилем.
- Добавлен SoC property-rule для `ro.soc.model`, `ro.vendor.soc.model`, `ro.hardware.chipname`, `ro.vendor.qti.soc_model` и других распространённых алиасов, используемых DevCheck и аналогичными приложениями.
- Исправлены устаревшие имена настроек SoC в существующих локальных базах; очищать данные XPL-EX не требуется.
- GPU renderer/vendor и OpenGL ES выбираются по реальному SoC модели и не смешиваются со случайным чипом.

## Батарея, дисплей и память

- Ёмкость батареи, процент, charge counter, energy counter, статус, питание, циклы, напряжение и температура формируются согласованно.
- Проектная ёмкость подменяется через `PowerProfile.getBatteryCapacity()` и sysfs `charge_full`/`charge_full_design`, поэтому диагностические приложения больше не показывают родную батарею при выбранном профиле.
- Дисплей получает реальные для модели разрешение, density DPI и частоту обновления через `Display`/`Display.Mode`.
- Убрано нереальное значение RAM 900 GB; общий и доступный объём памяти соответствуют конфигурации модели.
- Количество камер и пакет штатной камеры согласованы с производителем.

## Setting Values и автоматическая активация

- Значения, которые реально потребляются назначенными хуками приложения, подсвечиваются зелёным.
- После **Save** автоматически назначаются хуки, использующие изменённые параметры, вместо сохранения неактивных значений.
- Автоактивация охватывает Android/Build, Apps, Battery, Bluetooth, Cell, Device, Display, Files, Hardware, Network, Notification, Props, Settings, SoC, Unique, User, XPLEX и Zone.
- Для раздела Device автоактивация учитывает brand/manufacturer, удаляет старые несовместимые OEM ID-хуки и оставляет только правильный.
- При открытии Setting Values отмечаются только параметры уже назначенных хуков; ручный выбор пользователя сохраняется.

## Русская справка

- Добавлены русские описания основных групп хуков без переименования английских функций.
- Добавлены пояснения для всех разделов Setting Values и отдельных параметров.
- Исправлено разрешение справки по исходному ключу настройки, поэтому одинаково названные элементы открывают правильный текст.

## Интерфейс UI 1.5.8

- Добавлен единый экран **Расширенные настройки**.
- Добавлены системная, светлая и тёмная темы, а также динамические цвета Monet на Android 12+.
- Главное окно, справка, редакторы и списки получили Material Toolbar и корректные отступы от системных панелей.
- Обновлено боковое меню; настройки темы, языка и журналов перенесены в расширенные настройки.
- Добавлен понятный экран состояния модуля с возможностью продолжить открытие приложения.
- Обновлены окна редактирования, плавающие кнопки, Snackbar и выделение системных приложений.

## Совместимость и надёжность

- Версия bridge отделена от отображаемой версии APK: UI-релиз `1.5.6` сохраняет совместимый bridge ABI `1.5.5` и не показывает ложную ошибку несовпадения после обновления.
- Release-сборка не использует R8/minification, поскольку оптимизация удаляла динамически вызываемые Xposed/Lua-классы и ломала хуки.
- Централизована защита временных меток Google Play Services/DroidGuard.
- Исправлена рекурсия `TimeInterceptor` при чтении времени изменения файла.
- Обновлены AndroidX, Gradle/Android Gradle Plugin и Java 17; добавлены baseline profiles.
- Добавлены unit-тесты профилей, Universal Gaming Spoof, автоактивации, справки, SoC и защиты временных меток.

## Установка

- Package name: `eu.faircode.xlua`
- Version name: `1.5.6`
- Version code: `155`
- Min SDK: 23
- Target SDK: 34

APK подписывается настроенным release-ключом репозитория. После обновления необходимо перезагрузить устройство, чтобы LSPosed загрузил новые определения. Затем для уже настроенного приложения выключите и снова включите **Spoof Device**, сохраните профиль и принудительно остановите целевое приложение.
