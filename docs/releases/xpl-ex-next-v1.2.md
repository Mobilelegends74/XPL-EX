# Изменения после предыдущей сборки

- Добавлены системные каталоги приложений, соответствующие выбранным Google Pixel, Samsung, Xiaomi/POCO, OnePlus, ASUS/ROG, Nubia/REDMAGIC, Vivo/iQOO, Lenovo, Motorola и Meizu.
- Все 58 профилей автоматически сопоставляются со своим OEM-каталогом; для игровых и складных моделей добавлены модельные системные компоненты.
- Добавлен отдельный случайный список из 10–18 популярных пользовательских приложений. Он меняется вместе с выбранной моделью и заводской сборкой, а реальные приложения устройства остаются изолированными.
- Исправлена классификация виртуальных приложений: OEM-компоненты отображаются как системные, популярные приложения — как пользовательские.
- Устранена утечка родного значения `REDMAGICOS10.07.MR_EU1` в поле сборки. `Build.DISPLAY` теперь формируется только из `buildId` и `incremental` выбранного заводского fingerprint.
- Приложение и APK переименованы в `XPL-EX-NEXT-1.5.6` без изменения совместимых `versionCode 155` и bridge ABI `1.5.5`.
