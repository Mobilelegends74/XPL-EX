# XPL-EX-NEXT v1.6.4

Исправления поддержки рабочих профилей по [issue #9](https://github.com/Mobilelegends74/XPL-EX/issues/9):

- назначения work profile корректно загружаются и не смешиваются с user 0;
- гарантируется создание таблицы `groups` в старых базах;
- defaults коллекции, темы и debug не перезаписывают настройки владельца при открытии другого профиля;
- Global Settings и hook enforcement используют глобальные значения текущего Android-профиля;
- исправлена запись профильно-зависимых настроек коллекций;
- удалено недостижимое условие определения single-app режима.

Версия `1.6.4`, `versionCode 169`; подпись сохранена прежней для установки поверх предыдущих релизов.

Если проблемы с work profile сохранятся, создайте новое issue с шагами воспроизведения, SQLite-дампом без персональных данных и LSPosed-логом.
