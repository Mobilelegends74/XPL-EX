# Изменения относительно XPL-EX-NEXT v1.5.7

- Модуль полностью переведён с legacy Xposed API на современный **libxposed API 101** для **LSPosed v2.1.1 (7790)**.
- Legacy entry point `assets/xposed_init`, старые manifest-метаданные и зависимость Xposed API 82 заменены на `META-INF/xposed` и современный `XposedModule` entry point.
- Существующие Lua/application/framework hooks перенесены на interceptor chain API 101 с сохранением обработки `before`, `after`, аргументов, результата и исключений.
- System Server запускается через `onSystemServerStarting`; Settings Provider корректно подключается после загрузки его пакета внутри `system_server`. Динамический выбор пользовательских приложений в LSPosed сохранён.
- В журнал добавлены отдельные отметки загрузки модуля, установки хуков и первого фактического выполнения хука.
- `versionCode` обновлён до **158** и синхронизируется по версии реально загруженного кода. Версия APK больше не зависит от кэша PackageManager и отделена от совместимого bridge-протокола **1.5.5**.
- Минимальная версия Android повышена до Android 8.0 (API 26), как требуется libxposed API 101. Native-компоненты модулю не требуются.

После установки или обновления необходимо перезагрузить устройство, чтобы LSPosed загрузил новую версию в `system_server` и выбранные приложения.
