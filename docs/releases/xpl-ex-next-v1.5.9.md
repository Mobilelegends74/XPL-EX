# XPL-EX-NEXT v1.5.9

- Закрыта утечка списка установленных приложений через `PackageManager.getPackagesForUid`: результат фильтруется по правилам Apps Spoof List EX и остаётся согласованным с виртуальным каталогом пакетов.
- Уже исправленное в ветке 1.5.8 FIX поведение батареи сохранено: Apps Spoof List EX не подключает старый Lua-перехватчик, фиксировавший заряд на 95%.
- Закрыты прямые пути чтения реального локального IPv4/IPv6 через `NetworkInterface`, `InterfaceAddress`, `WifiInfo`, `WifiManager` и `ConnectivityManager`; существующие parcel-, `getifaddrs`- и ioctl-перехватчики сохранены.
- Для более безопасной первичной настройки добавлены отдельные необязательные коллекции: `Applist`, `Spoof`, `Hardware` и `Advanced`. В них перенесены группы Apps Spoof List, Apps Spoof Timestamps, Hardware, Spoof Features, Storage Isolate и Spoof Storage Size согласно назначению.
- Спуф количества циклов зарядки снова применяется сразу со значением по умолчанию `120`, даже если пользователь ещё не создавал отдельную настройку.
- Диапазоны рандомизации Charging Cycles и Boot Count ограничены значениями `100–500` включительно.
- Версия приложения и APK обновлена до `1.5.9` (`versionCode 159`); bridge-протокол совместимости сохранён на версии `1.5.5`.

После установки необходимо перезагрузить устройство, чтобы LSPosed загрузил новую версию во все выбранные приложения. Новые необязательные коллекции включаются пользователем по необходимости.
