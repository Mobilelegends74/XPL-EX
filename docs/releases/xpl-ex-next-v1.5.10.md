# XPL-EX-NEXT v1.5.10

- Исправлено вводящее в заблуждение отображение fingerprint в **Settings Values**: значок снова показывается только у параметров, которые классификатор XPL-EX считает обычно пригодными для отслеживания устройства или пользователя.
- При наличии несохранённых значений на месте статусного индикатора по-прежнему показывается предупреждение, имеющее более высокий приоритет, чем fingerprint.
- Рядом с каждым параметром добавлен отдельный значок со знаком вопроса. По нажатию он открывает подробное описание именно этого параметра, не смешивая справку со смыслом fingerprint.
- Для групп **Settings Values** справка также вынесена в отдельный значок со знаком вопроса, а прежний статусный значок оставлен только для предупреждения о несохранённых значениях.
- Нажатие на видимый fingerprint объясняет, почему значение относится к уникальным данным.
- Версия приложения и APK обновлена до `1.5.10` (`versionCode 160`); bridge-протокол совместимости сохранён на версии `1.5.5`.

Изменение исправляет замечание из [issue #2](https://github.com/Mobilelegends74/XPL-EX/issues/2) и не меняет логику спуфинга или наборы хуков.

После установки необходимо перезагрузить устройство, чтобы LSPosed загрузил новую версию во все выбранные приложения.
