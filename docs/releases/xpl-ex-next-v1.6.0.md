# XPL-EX-NEXT v1.6.0

- Исправлены хуки `getSimOperator`, `getSimOperatorName`, `getNetworkOperator` и `getNetworkOperatorName`: теперь они возвращают значения из выбранного профиля **Cell**, а не константы `00101` и `unknown`.
- Для каждой SIM используется соответствующий индекс настроек: имя оператора берётся из `cell.operator.name`, числовой код — из `cell.operator.numeric.id` или, при его отсутствии, собирается из MCC и MNC.
- Все четыре хука объединены в отдельную группу и автоматически назначаются приложению при сохранении связанных параметров Cell; существующие назначения сохраняются, поскольку ID хуков не изменились.
- Добавлена фоновая проверка последнего релиза `Mobilelegends74/XPL-EX`. При появлении более новой версии модуль предлагает скачать подписанный APK; проверка выполняется не чаще одного раза в 12 часов.
- GitHub Actions переведён на единый постоянный сертификат релиза и проверяет его SHA-256 перед публикацией. Начиная с `1.6.0`, следующие версии устанавливаются поверх предыдущей без удаления приложения.
- Версия приложения и APK обновлена до `1.6.0` (`versionCode 163`); bridge-протокол совместимости сохранён на версии `1.5.5`.

Изменение исправляет замечание из [issue #5](https://github.com/Mobilelegends74/XPL-EX/issues/5).

> Важно: релиз `1.5.12` был подписан одноразовым ключом CI. Android не разрешает сменить подпись установленного APK, поэтому перед первым переходом на `1.6.0` необходимо экспортировать настройки, удалить старую версию и установить `1.6.0`. Это одноразовая миграция; последующие релизы будут иметь ту же подпись.

После установки необходимо перезагрузить устройство, чтобы LSPosed загрузил новую версию во все выбранные приложения.
