# Исправления относительно XPL-EX-NEXT v1.5.8

- Исправлена безопасная миграция назначений хуков для существующих баз данных после перехода на API 101 без удаления параметров и пользовательских настроек.
- Исправлено скрытие камеры, Wi-Fi, телефонии и других аппаратных возможностей: устаревшие хуки `PackageManager.hasSystemFeature` и `getSystemAvailableFeatures` больше не заменяют реальные системные результаты.
- Исправлена загрузка сохранённых назначений из актуальной таблицы `assignments`, включая совместимость со старой таблицей `assignment`.
- Устранены ошибочные типы параметров в сетевых хуках и некорректное имя параметра общей памяти.
- Исправлены ошибки выполнения хуков `LinkProperties`, `WifiInfo`, Binder и файловых перехватчиков на современных версиях Android.
- Добавлена безопасная обработка отсутствующих системных полей, необязательных классов, старой таблицы `groups` и несовместимых классов рандомизаторов.
- Исправлены ошибки форматирования диагностических сообщений и лишние сообщения об ожидаемо отсутствующих классах и Lua-функциях.
- Добавлены регрессионные тесты миграции базы, сохранности параметров и выполнения хуков через API 101.

После установки необходимо перезагрузить устройство, чтобы LSPosed загрузил исправленную версию во все выбранные приложения.
