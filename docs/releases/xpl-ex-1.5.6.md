# XPL-EX 1.5.6 (155)

Эта версия основана на оригинальной ветке `0bbedCode/XPL-EX:new` и сохраняет существующую архитектуру XPL-EX. Ниже перечислены изменения нашей ветки относительно оригинальной базы.

## Universal Gaming Spoof

- В начало списка хуков добавлен отдельный раздел **Universal Gaming Spoof** с переключателем **Spoof Device**.
- Один переключатель включает согласованный набор хуков модели устройства, Android Build, SoC, CPU/GPU, памяти, дисплея, батареи, камеры, системных и рекламных идентификаторов, SIM/телефонии, сети, Wi-Fi, аккаунтов, часового пояса, языка, User-Agent и размера хранилища.
- Для фирменных Device ID включается только группа производителя выбранного профиля. Одновременное включение Lenovo, ASUS, Meizu, Vivo, OnePlus, Samsung и Xiaomi ID устранено.
- Неподтверждённые значения `/proc/cpuinfo` и GNSS-модели не включаются автоматически, чтобы не смешивать характеристики разных устройств.

## Реальные согласованные профили устройств

- Добавлен каталог из **58 реально существующих моделей** и **80 совместимых Android-сборок**.
- Каталог включает Google Pixel, ASUS/ROG, Lenovo Legion, Meizu, Motorola, Nubia/RedMagic, OnePlus, POCO, Samsung, Vivo/iQOO и Xiaomi.
- Для ASUS, Lenovo, Meizu, Motorola, OnePlus, POCO, Samsung, Vivo и Xiaomi добавлено по пять моделей; Nubia и RedMagic вместе представлены пятью игровыми моделями.
- Рандомизация сбалансирована между брендами: серия Google Pixel больше не выпадает почти при каждом запуске.
- Модель, manufacturer, brand, product, codename, fingerprint, версия Android и API выбираются как единый реальный профиль.
- С тем же профилем согласуются SoC, архитектура и ABI, GPU, RAM, разрешение, плотность и частота дисплея, ёмкость и состояние батареи, количество камер и другие аппаратные параметры.
- Добавлена проверка профилей: несовместимые версии Android, API, fingerprint и характеристики модели отбрасываются до рандомизации.
- Старые независимые генераторы, создававшие смешанные и нереальные комбинации, заменены единым профилем устройства.

## Дисплей, батарея и аппаратные данные

- Хуки `DisplayMetrics` теперь подменяют не только ширину и высоту, но и реальную плотность DPI.
- Добавлена подмена фактической частоты обновления через `Display.getRefreshRate()` и `Display.Mode.getRefreshRate()`.
- Батарейный профиль согласован с моделью: ёмкость, процент, статус зарядки, подключение питания, циклы, напряжение и температура.
- Параметр числа циклов зарядки подключён к реальным battery hooks и больше не остаётся неиспользуемым значением.
- GPU/OpenGL возвращает данные выбранного профиля без смешивания со случайным GPU другой модели.

## Связь Setting Values с хуками

- Значения, которые реально используются активными хуками приложения, подсвечиваются зелёным.
- После изменения значения и нажатия **Save** приложение автоматически активирует полный соответствующий раздел хуков, а не оставляет сохранённое значение неиспользуемым.
- Автоактивация поддерживает Android/Build, Apps, Battery, Bluetooth, Cell, Device, Display, Files, Hardware, Network, Notification, Props, Settings, SoC, Unique, User, XPLEX и Zone.
- При открытии **Setting Values** автоматически ставятся галочки только у параметров, используемых уже назначенными хуками выбранного приложения.
- Целая категория без необходимости не отмечается; ручные отметки пользователя сохраняются. После этого можно сразу нажать **Spoof**, затем **Save**.

## Русские справочные описания

- Добавлены понятные русские описания по кнопке `?` для всех основных групп хуков; английские названия функций не переименовывались.
- Добавлены русские пояснения по значку отпечатка для всех разделов Setting Values.
- Добавлены краткие описания действий для каждого отдельного параметра внутри разделов без повторения его названия.
- Всего добавлено 83 описания хуков, 21 описание разделов и 208 описаний отдельных значений.

## Исправления из анализа XPL-EX 1.5.8

- Защита временных меток Google Play Services/DroidGuard централизована и расширена на критичные пути GMS.
- Исправлена рекурсия `TimeInterceptor` при чтении времени изменения/смены файла, которая могла привести к сбою.
- Сохранены уже присутствовавшие корректные исправления Location и безопасного обновления чекбоксов без повторного переноса декомпилированного кода.

## Интерфейс, производительность и сборка

- Исправлено попадание элементов интерфейса под строку состояния на устройствах с современным Android.
- Обновлены AndroidX-компоненты и добавлена установка baseline profiles.
- Проект переведён на современную связку Gradle/Android Gradle Plugin и Java 17.
- Release APK оптимизируется R8; динамически используемые Xposed/Lua-классы и ресурсы защищены правилами ProGuard.
- Удалены только тестовые assets и устаревшие независимые генераторы, заменённые согласованными профилями; рабочие хуки XPL-EX сохранены.
- Добавлено 36 unit-тестов для профилей, Universal Gaming Spoof, зависимостей Setting Values, русских описаний и защиты временных меток.

## Установка

- Package name: `eu.faircode.xlua`
- Version name: `1.5.6`
- Version code: `155`
- Min SDK: 23
- Target SDK: 34

APK из GitHub Actions подписывается настроенным release-ключом, если в репозитории заданы secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` и `KEY_PASSWORD`. Без этих secrets используется временный CI-ключ. Если установленная копия XPL-EX подписана другим сертификатом, перед установкой сохраните конфигурацию и удалите старую APK.
